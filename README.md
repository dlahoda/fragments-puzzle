# Fragments Puzzle

Програма знаходить найдовший однорядний цифровий пазл із набору фрагментів.

Фрагменти можна з'єднати, якщо останні дві цифри першого фрагмента збігаються з першими двома цифрами наступного. Кожен фрагмент можна використати не більше одного разу.

Наприклад:

```text
248460 + 608017 + 177092
```

Результат:

```text
24846080177092
```

## Вимоги

- Node.js 20 або новіший
- npm

## Встановлення

```bash
npm install
```

## Запуск

Передайте шлях до вхідного файлу після `--`:

```bash
npm start -- source.txt
```

Для іншого набору фрагментів:

```bash
npm start -- path/to/fragments.txt
```

Програма виведе знайдену найдовшу послідовність у стандартний потік виведення.

## Формат вхідного файлу

Файл повинен містити цифрові фрагменти, розділені пробільними символами — наприклад, переносами рядків або пробілами.

Кожен фрагмент:

- складається лише з цифр;
- містить щонайменше дві цифри;
- може мати довжину, відмінну від довжини інших фрагментів.

Приклад:

```text
608017
248460
962282
994725
177092
```

Файл `source.txt` містить початковий набір із 142 фрагментів. Файл `random-100.txt` містить додатковий набір із фрагментами різної довжини.

## Перевірка типів

```bash
npm run check
```

Команда перевіряє TypeScript-код без створення JavaScript-файлів.

## Як працює розв'язання

Задача представляється як орієнтований граф:

- двозначні початки й закінчення від `00` до `99` є вершинами;
- кожен фрагмент є орієнтованим ребром від його перших двох цифр до останніх двох;
- шуканий пазл є найдовшим шляхом без повторного використання ребер.

Програма використовує пошук у глибину із поверненням (`DFS` і `backtracking`). Для прискорення пошуку вона:

- заздалегідь групує фрагменти за першими двома цифрами;
- зберігає використані фрагменти в бітовій масці `BigInt`;
- запам'ятовує вже відвідані стани пошуку;
- застосовує `branch and bound`, щоб не досліджувати гілки, які гарантовано не можуть покращити поточний результат.

Алгоритм шукає точну відповідь. Оскільки задача комбінаторна, час роботи в найгіршому випадку може зростати експоненційно залежно від структури вхідних даних.

## Джерела та допомога

Під час розробки OpenAI ChatGPT/Codex використовувався як навчальний асистент для пояснення та перевірки ідей графового пошуку, DFS, backtracking, бітових масок, кешування станів і branch and bound. Фінальне рішення було адаптоване та перевірене автором.
